# Проверка обновления от 12 ноября 2026

База — последний загруженный BlockBlast3D(2).zip. Правила Game.cpp, HUD renderer, библиотеки и BAT сохранены; графика и управление обновлены в исходной структуре src/assets.

Среда: Linux, GCC 14.2, CMake 4.4.4, C++17 Release; реальный OpenGL 4.5 core Mesa llvmpipe через EGL. Шейдеры используют GLSL 330.

Пройдены:

- GameLogic: прежние тесты правил, очистки линий, refill, Game Over и demo.
- EnvironmentAndSun: нормализация и управление солнцем, ограничение высоты 8–82°, reset, конечные трансформы и положительные размеры объектов всех трёх локаций, снижение числа объектов в LOW.
- RealOpenGL: компиляция/link всех шейдеров, полнота shadow FBO, рендеринг трёх сцен, отсутствие ошибок OpenGL, фактическое изменение пикселей сцены при переключении теней.
- Demo placement через экранные координаты даёт 120 очков; смена сцен сохраняет счёт и вектор солнца.
- Поворот/масштаб камеры не меняет вектор солнечного освещения.
- Сравнение неба при переносе камеры с сохранением ориентации подтверждает отсутствие параллакса солнца.
- Пауза, help, LOW, ручное управление солнцем, reset, resize до 960×600 проходят рендеринг.
- Реальные снимки парка, пляжа и зимы проверены визуально.

Windows GLFW-окно, BAT и аппаратный FPS на компьютере команды здесь не проверялись. Предупреждение deprecated внутри стороннего GLM не мешает сборке.

Повторение в Linux с EGL:

```bash
cmake -S . -B build-check -DBLOCKBLAST_HEADLESS_BUILD=ON -DBLOCKBLAST_EGL_TEST=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build-check --parallel
ctest --test-dir build-check --output-on-failure
```

Headless-режим предназначен для проверки в Linux, а не обычного запуска окна. На Windows используйте неизменённый BUILD_AND_RUN.bat и не включайте EGL/headless.
